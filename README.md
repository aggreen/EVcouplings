# EVcouplings

Predict protein structure, function and mutations using evolutionary sequence covariation.

## Version

This is a custom version of EVcouplings designed to perform sensitive search against the RCSB PDB for experimental protein structures. This code supports analysis in Green et al, 2025, forthcoming. If you are looking for the original published version(s) of EVcouplings, [look here](https://github.com/debbiemarkslab/EVcouplings)
